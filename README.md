# hl-trade

Hyperliquid 用の自分専用トレード画面です。HTML 1 枚で動き、価格・チャート・板・ポジション・履歴を取引所の公開 API から読みます。

- 開く: https://sakusakureformexpress-design.github.io/hl-trade/
- 見本モード: 注文ボタンは送る中身を表示するだけで、取引所には何も送りません。
- 鍵やアドレスはこのリポジトリに入っていません。口座アドレスは各端末のブラウザに保存されます。

## アプリの手数料（任意・初期状態はオフ）

Hyperliquid の「ビルダーコード」で、約定額の一部をアプリの運営に受け取る仕組みを入れてあります。**初期状態では何も変わりません**（手数料なし）。

### 有効にする

`index.html` の `BUILDER` を書き換えます。

```js
const BUILDER = {addr:'0x…受け取る口座…', fee:10, required:true};
```

- `addr`：手数料を受け取る口座。**パーペチュアル口座に 100 USDC 以上**ないと、取引所に受け付けてもらえません。
- `fee`：1/10 bp 単位。`10` = 0.01%、`30` = 0.03%、`100` = 0.1%（パーペチュアルの上限。現物は1%まで）。
- `required`：`true` のあいだ、承認していない人は**新しい注文を出せません**。**決済・取り消し・倍率変更は承認なしでもできます**（ポジションから出られなくならないように）。

### 利用者の側

- 「本番の注文の設定」に、料率・受け取り口座・承認の状態が出ます。承認は**ウォレットの署名**（`ApproveBuilderFee`）で行い、お金は動かず秘密鍵も使いません。取り消し（0% の承認）もできます。
- 注文の確認画面に「アプリの手数料」が出ます（現物の買いは対象外）。
- 承認はメインのウォレットの署名が必要です（注文用の鍵では承認できない決まりです）。パソコンの MetaMask などか、ウォレットアプリの中のブラウザで開く必要があります。iPhone の Safari 単体ではウォレットが見つからず承認できません。

### 動作確認の範囲

- 注文の署名用ハッシュ（`builder` 付き）と、承認の署名データは、公式の Python SDK の出力と**完全に一致**することを確かめました。
- 未承認のとき、新規注文だけが止まり、決済と取り消しは通ることを確かめました。
- **実際の取引所での承認・約定は、まだ確かめていません。** 公開前に、少額で一度通して確認してください。
