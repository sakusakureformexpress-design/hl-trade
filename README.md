# hl-trade

Hyperliquid 用のトレード画面です。HTML 1 枚で動き、価格・チャート・板・ポジション・履歴を取引所の公開 API から読みます。
日本語・한국어・English を画面の上で切り替えられます。

- 開く: https://sakusakureformexpress-design.github.io/hl-trade/
- 試す（架空のデータ・取引所にはつながらない）: `index.html?demo`
- 見本モード（練習）: 注文ボタンは送る中身を表示するだけで、取引所には何も送りません。
- 鍵やアドレスはこのリポジトリに入っていません。口座アドレスは各端末のブラウザに保存されます。

## できること

- **先物も現物も、取引所にあるものを全部**：先物は上場廃止を除く全銘柄、現物は USDC 建ての全ペア。「🔍 すべての銘柄」（または `/` キー）で検索・並べ替えができ、★でお気に入りにした銘柄が上の帯に並びます（はじめは BTC・ETH・XRP・HYPE・SOL・DOGE・SUI・LINK・ADA・AVAX）。
- **言語**：日本語 / 한국어 / English。ブラウザの言語を見て最初の言語を決め、右上のボタンでいつでも切り替えられます（画面は作り直されるだけで、開いている鍵や設定は消えません）。
- **通貨表示**：日本語は円、한국어は원、English はドルだけ。為替は無料の公開 API（下記）から自動で取ります。
- ニュースや予定表は載せていません（下の「ニュースについて」）。

## 訳文を直す・足す

画面の文字は `_('日本語の文')` を通して出しています。日本語の文がそのまま訳文表のキーです。訳文表は `index.html` の `<script id="dict">` の中にあり、1 行 1 文です。

```js
"約定　{0}　{1}　{2} @ {3}": "Filled {0} {1} {2} @ {3}",
```

- `{0}` `{1}` は差し込む値の場所です。順番は入れ替えてかまいません。
- 訳文表にない文は日本語のまま出ます。`?debug` を付けて開くと、足りない文がコンソールに出ます。
- 新しい言語を足すときは、`LANGS`・`LOCALES`・訳文表に 1 つ足します。

## アプリの手数料（任意・初期状態はオフ）

Hyperliquid の「ビルダーコード」で、約定額の一部をアプリの運営に受け取る仕組みを入れてあります。**初期状態では何も変わりません**（手数料なし）。

`index.html` の `BUILDER` を書き換えると有効になります。

```js
const BUILDER = {addr:'0x…受け取る口座…', fee:10, required:true};
```

- `addr`：手数料を受け取る口座。**パーペチュアル口座に 100 USDC 以上**ないと、取引所に受け付けてもらえません。
- `fee`：1/10 bp 単位。`10` = 0.01%、`30` = 0.03%、`100` = 0.1%（パーペチュアルの上限。現物は 1% まで）。
- `required`：`true` のあいだ、承認していない人は**新しい注文を出せません**。**決済・取り消し・倍率変更は承認なしでもできます**（ポジションから出られなくならないように）。

利用者の側では、「本番の注文の設定」に料率・受け取り口座・承認の状態が出ます。承認はウォレットの署名（`ApproveBuilderFee`）で、お金は動かず秘密鍵も使いません。取り消し（0% の承認）もできます。注文の確認画面にも「アプリの手数料」が出ます。承認はメインのウォレットの署名が必要なので、パソコンの MetaMask などか、ウォレットアプリの中のブラウザで開く必要があります（iPhone の Safari 単体では承認できません）。

> 手数料を取って他人の取引を仲介することは、国によっては暗号資産交換業・金融商品取引業などの規制の対象になりえます。公開前に、サービスを提供する国ごとの扱いを専門家に確認してください。

## ニュースについて

以前あった「重要な予定」の帯と予定表は外しました（手で入れる予定と、毎日の自動更新が必要だったため）。取引所の公開 API に、ニュースや予定を返すものは見つかりませんでした。画面が使っている外部の宛先は次の 4 つだけです。

| 宛先 | 使い道 |
|---|---|
| `api.hyperliquid.xyz`（HTTP と WebSocket） | 価格・チャート・板・口座・注文 |
| `api.frankfurter.app` / `open.er-api.com` | 為替（日本語・한국어のときだけ） |
| `fonts.googleapis.com` | 文字の書体 |

## デモ

`index.html?demo` で開くと、`demo.js`（模擬取引所）につながります。価格・板・ローソク足・ポジション・注文・約定が架空のデータで動き、本物の取引所には一切つながりません。鍵の暗証番号は画面の帯に出ます。claude.ai の Artifact のように外に通信できない場所では、`tools/make-preview.py` で 1 枚にまとめたデモ版を作れます。

## 検証

`tests/` に、画面の操作テストと署名の照合があります（Playwright・Node・Python）。詳しくは `tests/README.md`。

- 署名：注文・取り消し・変更・倍率・証拠金・手数料つき注文を 250 通りランダムに作り、画面の署名部品（外部ライブラリなし）の出力が公式 Python SDK と一致することを確かめています。
- 言語：韓国語・英語の全画面に日本語の取りこぼし・`{0}` の差し込み忘れ・訳文表にない文がないこと、言語の切り替え後の表示が最初からその言語で開いたときと一致することを確かめています。

## できないこと

- **HIP-3（他の事業者が立てた先物市場、`xyz:` など）の新規注文**：表示（履歴）はできますが、注文は先物（メインの市場）と現物だけです。
- 本物の取引所での動作確認は、この環境からはできていません。公開前に、少額で一度通してください。
